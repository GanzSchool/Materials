# SQL

Az SQL tananyag két nagy egységre épül:

- **Adatbázis-kezelés 1** – SQL alapok, egytáblás lekérdezések, adatkezelés és összefoglaló gyakorlás.
- **Adatbázis-kezelés 2** – relációs adatbázisok, többtáblás lekérdezések és a 13. évfolyam haladó témái.

Az **Adatbázis-kezelés 1** fejezetben az elérhető forrásanyagok alapján elkészült tananyagok már megnyithatók a bal oldali menüből. A példák és indító scriptek MariaDB-hez készülnek.
