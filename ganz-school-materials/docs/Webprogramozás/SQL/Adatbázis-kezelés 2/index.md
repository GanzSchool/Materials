# Adatbázis-kezelés 2

## Tervezett témák

- Relációs adatbázisok ismétlése
- Elsődleges és idegen kulcsok
- 1:1, 1:N és N:M kapcsolatok
- Kapcsolótáblák
- Adatbázis-tervezés és ER-diagram
- Normalizálás: 1NF, 2NF, 3NF
- Referenciális integritás
- `INNER JOIN`
- `LEFT JOIN` és további JOIN-típusok
- Több tábla összekapcsolása
- N:M kapcsolatok lekérdezése
- `JOIN` + `WHERE` + `ORDER BY`
- `JOIN` + aggregáló függvények
- `JOIN` + `GROUP BY` + `HAVING`
- Allekérdezések
- `IN`, `EXISTS`
- `CASE`, `COALESCE`
- `UNION`
- Tranzakciók: `COMMIT`, `ROLLBACK`
- Nézetek és indexek
- Import, export és adatbázis-dump
- SQL használata backendből
- Paraméterezett lekérdezések
- CRUD REST API adatbázissal
- ORM alapok
- Komplex vizsgafeladatok
